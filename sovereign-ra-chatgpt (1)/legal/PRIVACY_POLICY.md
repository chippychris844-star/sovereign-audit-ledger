# Resolution AI Privacy Policy

Resolution AI is a local-first assistant. Chats, uploaded evidence, knowledge graph nodes, settings, and audit logs are stored locally. On Windows, the launcher prefers D:\SovereignRA for private storage when D: exists.

Hosted model providers are used only when enabled and configured by the user. Hosted outputs are treated as draft material and passed through RA Refinery before display.

Local file access is limited to approved folders. File write access is disabled by default and requires separate opt-in.
