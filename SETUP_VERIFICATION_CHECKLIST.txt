SETUP VERIFICATION CHECKLIST
================================================================================

Use this checklist after completing setup to verify all components are working.

================================================================================
PHASE 1: PRE-SETUP (on secondary laptop)
================================================================================

[ ] Windows 10 or Windows 11 (64-bit)
[ ] Administrator access available
[ ] Internet connection for downloading Fiddler
[ ] 2GB free disk space minimum
[ ] USB drive for transferring files (optional)
[ ] All files copied to: C:\setup\

Directory structure created:
  [ ] C:\setup\
  [ ] C:\Logs\Fiddler\
  [ ] C:\Logs\TaskScheduler\
  [ ] C:\Logs\Network\
  [ ] C:\Evidence\

Files in C:\setup\:
  [ ] ExportScheduledTasks.ps1
  [ ] ConfigureFirewall.ps1
  [ ] DailyEvidenceExport.bat
  [ ] SETUP_MONITORING_PACKAGE.md
  [ ] QUICK_START.txt


================================================================================
PHASE 2: FIDDLER INSTALLATION
================================================================================

[ ] Fiddler Classic installed to: C:\Program Files\Fiddler Classic\
[ ] Fiddler launches successfully (with Administrator privileges)
[ ] HTTPS Decryption enabled:
    [ ] Tools → Options → HTTPS
    [ ] "Capture HTTPS CONNECTs" checked
    [ ] "Decrypt HTTPS traffic" checked
[ ] Root Certificate trusted:
    [ ] Certificate installed in Windows
    [ ] Verify in: Settings → "Manage certificates"
[ ] Logging configured:
    [ ] Tools → Options → Logging
    [ ] Path set to: C:\Logs\Fiddler\
    [ ] "Log all sessions to file" enabled
[ ] Test capture:
    [ ] Open web browser
    [ ] Visit https://www.google.com
    [ ] Confirm request appears in Fiddler


================================================================================
PHASE 3: FIREWALL CONFIGURATION
================================================================================

[ ] PowerShell script executed successfully:
    powershell -ExecutionPolicy Bypass -File "C:\setup\ConfigureFirewall.ps1"

[ ] Rules created (verify in Settings → Windows Firewall → Advanced):
    [ ] Block-alibaba.com
    [ ] Block-alicdn.com
    [ ] Block-mmstat.com
    [ ] Block-phoenix-gw.alibaba.com
    [ ] Block-iflow.alibaba.com
    [ ] Block-acs.aliyun.com

[ ] All rules show:
    [ ] Direction: Outbound
    [ ] Action: Block
    [ ] Enabled: Yes

PHASE 4: TASK SCHEDULER BASELINE
================================================================================

[ ] Export script completed successfully:
    powershell -ExecutionPolicy Bypass -File "C:\setup\ExportScheduledTasks.ps1"

[ ] Baseline files created:
    [ ] C:\Logs\TaskScheduler\AllScheduledTasks_YYYYMMDD_HHMMSS.csv (exists)
    [ ] C:\Logs\TaskScheduler\TaskExports_YYYYMMDD_HHMMSS\ (directory exists)

PHASE 6: NETWORK MONITORING
================================================================================

[ ] Fiddler window:

    [ ] "Capturing" indicator active

[ ] Test blocked destination:

    [ ] Connection should fail with firewall block
