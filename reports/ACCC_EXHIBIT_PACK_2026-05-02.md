## Purpose

This pack is a source-indexed exhibit bundle for a consumer/service-failure complaint. It is written to be factual and readable, with the goal of preserving the exact evidence trail rather than turning the corpus into a narrative that outruns the sources.

## Handling Note

- Verified source text is separated from inference.
- Unsupported claims remain marked as unverified.
- Sensitive credentials found during scanning were not copied into this pack.
- Refund values are kept source-specific so the pack does not double count amounts that appear in different ledgers.
